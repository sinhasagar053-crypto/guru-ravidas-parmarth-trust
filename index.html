FAQ

Frequently Asked Questions

क्या यह production backend है?

नहीं, यह premium frontend demo है। PHP/MySQL, secure authentication और payment gateway को production में जोड़ना होगा।

क्या membership fee बदली जा सकती है?

हाँ। Demo fees JavaScript configuration में हैं; production में database/Admin Dashboard से manage करें।

क्या Aadhaar/PAN store किया गया है?

नहीं। इस frontend में sensitive identity data storage नहीं है। Production में encrypted और access-controlled storage जरूरी है।
